# Thai fonts

Thai UI uses Noto Sans Thai for body/controls and Noto Serif Thai for editorial
headings. Both variable TTFs are bundled for offline, deterministic rendering.
English retains the existing system body and Georgia headings.

Downloaded on 2026-10-18 from the official Google Fonts repository:

- [Noto Sans Thai](https://github.com/google/fonts/tree/main/ofl/notosansthai)
- [Noto Serif Thai](https://github.com/google/fonts/tree/main/ofl/notoserifthai)

Both fonts are redistributed under the SIL Open Font License, Version 1.1.
The unmodified licenses are included alongside their respective font assets.
